# Data Cleaning and Preparation

## Project Overview

The objective of this project is to clean and prepare a publicly available retail sales dataset for further analysis. The project focuses on identifying data quality issues and applying appropriate data cleaning techniques using Python and Pandas.

## Objectives

* Identify missing values and duplicate records.
* Detect inconsistent values and incorrect data types.
* Standardize text fields where appropriate.
* Validate the dataset after cleaning.
* Export a clean, analysis-ready CSV file.
